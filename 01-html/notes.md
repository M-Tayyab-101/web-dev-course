## What is HTML?
HTML is the skeleton of every webpage. It tells the browser 
what content exists on the page.

## Tags I already knew
- h1, h2, h3 → headings (h1 is biggest)
- p → paragraph
- ul, ol, li → lists (ul = bullets, ol = numbers)
- table, tr, th, td → tables
- br → line break

## New things I learned

### Attributes
Extra information inside a tag.
Format: <tagname attribute="value">

### Links
<a href="url">visible text</a>
- href = where it goes
- the text between tags = what user clicks

### Images
<img src="filename.jpg" alt="description">
- src = where the image is
- alt = text if image fails to load
- img has no closing tag

### Forms
<form> → wrapper for all inputs
<input type="text"> → single line text box
<input type="email"> → email field (validates @ symbol)
<input type="password"> → hides what you type
<input type="number"> → numbers only
<input type="checkbox"> → tick box
<label> → text label next to an input
<button type="submit"> → submits the form

## The golden rule
Every opening tag needs a closing tag EXCEPT:
- img, input, br → these are self-closing
